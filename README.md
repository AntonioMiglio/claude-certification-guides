## What Every Guide Contains

- **Part 1 — Foundations:** key concepts for each domain, with the official blueprint weights
- **Part 2 — Compact Guide:** principles to remember, quick to review right before the exam
- **Part 3 — Mock Exam:** original questions distributed in the same proportions as the real blueprint, plus bonus questions on topics standard practice sets tend to skip
- **Part 4 — Answers and Explanations:** the reasoning behind every correct answer, and why the other options don't hold up

## Important — NDA & Originality

None of these are real exam questions. The content of every Claude certification exam is confidential and covered by an NDA. Every question here is original, written from each exam's public guide and blueprint objectives, then reviewed with the help of Claude Opus 5.
